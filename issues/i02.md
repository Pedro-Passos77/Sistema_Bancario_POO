# I02 Fatura de dezembro não recebe juros em janeiro

Estado: relato preparado, ainda não publicado no GitHub Issues.
Prioridade: Alta. Regra: R05. Caso relacionado: U15.

## Ambiente

Linux, Java Runtime 17.0.20, ECJ 3.38.0 e JUnit Platform Console 1.10.2. Código Java original preservado. Reprodução assistida em 12/10/2026.

## Passos de reprodução

Criar cartão com fatura 100, indexMesDaFatura 11 e faturaPaga false. Definir mês Janeiro e chamar cobrarJurus.

## Resultado esperado

A fatura vencida deve receber juros, independentemente da interpretação numérica da taxa.

## Resultado observado

Fatura permanece 100.

## Análise e proposta

A comparação 0 > 11 ignora a mudança de ano. Armazenar período absoluto ou representar ano e mês.

## Evidência

evidencias/testes-unitarios.txt; executar CartaoCreditoTest, método u15 no identificador do teste.

As propostas ainda não foram aplicadas ao código original. A publicação deve ocorrer no bug tracker do fork, após revisão pelo integrante.
