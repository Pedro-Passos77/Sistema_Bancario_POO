# I05 Ajuste de limite permite valor negativo

Estado: relato preparado, ainda não publicado no GitHub Issues.
Prioridade: Média. Regra: H02 contrato proposto. Caso relacionado: U18.

## Ambiente

Linux, Java Runtime 17.0.20, ECJ 3.38.0 e JUnit Platform Console 1.10.2. Código Java original preservado. Reprodução assistida em 12/10/2026.

## Passos de reprodução

Criar cartão e fornecer -1 ao prompt de ajustarLimite.

## Resultado esperado

Rejeitar limite negativo; contrato proposto usa IllegalArgumentException.

## Resultado observado

Método retorna sem exceção e armazena limite -1.

## Análise e proposta

Validar domínio do limite e não atualizar estado em caso inválido.

## Evidência

evidencias/testes-unitarios.txt; executar CartaoCreditoTest, método u18 no identificador do teste.

As propostas ainda não foram aplicadas ao código original. A publicação deve ocorrer no bug tracker do fork, após revisão pelo integrante.
