# I06 Juros são reaplicados em chamadas no mesmo mês

Estado: relato preparado, ainda não publicado no GitHub Issues.
Prioridade: Alta. Regra: H03 pendente de validação. Caso relacionado: U19.

## Ambiente

Linux, Java Runtime 17.0.20, ECJ 3.38.0 e JUnit Platform Console 1.10.2. Código Java original preservado. Reprodução assistida em 12/10/2026.

## Passos de reprodução

Criar cartão com fatura 100 em janeiro. Definir Fevereiro. Chamar cobrarJurus duas vezes sem mudar o mês.

## Resultado esperado

Após a primeira cobrança, a segunda chamada do mesmo período deve preservar a fatura.

## Resultado observado

Primeira cobrança 1275; segunda 16256,25.

## Análise e proposta

Não há registro do último mês processado. Confirmar se o contrato do método garante idempotência por período.

evidencias/testes-unitarios.txt; executar CartaoCreditoTest, método u19 no identificador do teste.
