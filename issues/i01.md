# I01 Cobrança de juros multiplica a fatura por 12,75

Estado: relato preparado, ainda não publicado no GitHub Issues.
Prioridade: Alta. Regra: H01 pendente de validação. Caso relacionado: U14.

## Ambiente

Linux, Java Runtime 17.0.20, ECJ 3.38.0 e JUnit Platform Console 1.10.2. Código Java original preservado. Reprodução assistida em 12/10/2026.

## Passos de reprodução

Criar cartão com fatura 100, indexMesDaFatura 0 e faturaPaga false. Definir Ano como Fevereiro. Chamar cobrarJurus.

## Resultado esperado

Se 12.75 representa 12,75%, fatura 112,75 e receita 12,75.

## Resultado observado

Fatura 1275 e receita 1175.

## Análise e proposta

CartaoCredito.cobrarJurus multiplica por taxaJurus. Confirmar unidade da taxa antes de aprovar a correção.

## Evidência

evidencias/testes-unitarios.txt; executar CartaoCreditoTest, método u14 no identificador do teste.

As propostas ainda não foram aplicadas ao código original. A publicação deve ocorrer no bug tracker do fork, após revisão pelo integrante.
