# I03 Compra recusada altera mês da fatura e adia juros

Estado: relato preparado, ainda não publicado no GitHub Issues.
Prioridade: Alta. Regra: R02. Caso relacionado: U16.

## Ambiente

Linux, Java Runtime 17.0.20, ECJ 3.38.0 e JUnit Platform Console 1.10.2. Código Java original preservado. Reprodução assistida em 12/10/2026.

## Passos de reprodução

Criar cartão com fatura 900 em janeiro e limite 1000. Definir fevereiro. Chamar creditar(200), depois cobrarJurus.

## Resultado esperado

Recusar compra e preservar o mês original; a dívida anterior continua elegível a juros.

## Resultado observado

Fatura 900 e sem juros; creditar altera indexMesDaFatura mesmo quando setFatura rejeita a compra.

## Análise e proposta

Atualizar metadados somente quando a compra for aceita.

## Evidência

evidencias/testes-unitarios.txt; executar CartaoCreditoTest, método u16 no identificador do teste.

As propostas ainda não foram aplicadas ao código original. A publicação deve ocorrer no bug tracker do fork, após revisão pelo integrante.
