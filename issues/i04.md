# I04 Compra negativa é aceita e reduz a fatura

Estado: relato preparado, ainda não publicado no GitHub Issues.
Prioridade: Média. Regra: H02 contrato proposto. Caso relacionado: U17.

## Ambiente

Linux, Java Runtime 17.0.20, ECJ 3.38.0 e JUnit Platform Console 1.10.2. Código Java original preservado. Reprodução assistida em 12/10/2026.

## Passos de reprodução

Criar cartão novo. Chamar creditar(-100).

## Resultado esperado

Rejeitar valor negativo sem alterar estado; contrato proposto usa IllegalArgumentException.

## Resultado observado

Não ocorre exceção; fatura passa a -100.

## Análise e proposta

Distinguir operação de pagamento de operação de compra e validar valores na fronteira da operação.

## Evidência

evidencias/testes-unitarios.txt; executar CartaoCreditoTest, método u17 no identificador do teste.

As propostas ainda não foram aplicadas ao código original. A publicação deve ocorrer no bug tracker do fork, após revisão pelo integrante.
